## 体験の流れ
1. LINEで話しかける → 「投稿プランを作る」ボタンが返る
2. ボタン → LINE内の入力画面（LIFF）。業種（選択）・お店の一言（必須）、頻度・今月のイベント・強み・お客様像（任意）
3. 送信 → 投稿文が先に表示され、画像は1枚ずつ追加表示
4. 完成するとLINEに1週間分のカード（横スクロール）が届く。タップで全文・ハッシュタグ・コピー

## 方針の実装
| 方針 | 実装 |
|---|---|
| 事実は入力だけ | 日付はアプリ側で計算。AIには「入力にない料金・日付・特典は書かず【要確認】」と指示。画面では黄色で強調 |
| 誇大表現を避ける | 指示で禁止＋生成後に表現チェック（`src/lib/compliance.ts`）で該当語に注意表示 |
| 画像に文字を入れない | AIは文字なし背景のみ。見出し・店名・日付は日本語フォントでアプリ側が重ねる（`/api/plans/[id]/card/[index]`） |
| 人が最終確認 | 画面に「投稿前に必ず確認」。将来の自動投稿は承認ボタン経由（フェーズ3図） |
| 保存は最小限 | 保存は生成結果のみ（LINEのユーザーIDは保存しない）。7日後に自動削除（Cron） |
| 失敗への備え | 分かりやすいエラー文、画像失敗時は業種色の背景で代替、`/sample` に固定サンプル |

## 今後（交流会のあと）
### 2枚目以降のスライドを「おしゃれな型（テンプレート）」にする
- 目的: Instagramは見た目のおしゃれさが勝負。一度「お店の型」を作れば、毎週の投稿で使い回せるようにする（自分のお店の運用にも使う）。
- 流用元: `~/Desktop/AIエンジニア/design`（AIデザイン生成ツール）
  - 参考探し → 特徴を言葉にする（著作権に配慮し、画像そのものは渡さない） → 3案の設計、という流れ
  - デザインを「パーツ（レイヤー）」で持つ仕組み（`src/lib/poster/schema.ts`）。文字のパーツは「入れる言葉のID」だけを持つので、型に毎回ちがう文章を流し込める
  - フォントの選択肢、文字が枠に入らないときの自動縮小、行頭禁則（`render.ts`）
- 案: 型 = 表紙・中身・まとめの3種類のレイアウト（パーツの配置・色・フォント）。スライドの title / body を、型のテキストパーツに流し込む。
  今の `src/lib/slide-canvas.ts` を「型を読んで描く」形に置き換える。型はお店ごとに保存する。
